# Last Column 2 — Штурмовая колонна

Играть: https://dkuba.github.io/Mytopwar/

Самостоятельный браузерный crowd shooter с оригинальными процедурными моделями.
Чужие модели, текстуры, логотипы и звук Top War не используются.

## Что реализовано

- Светлая объёмная сцена: игрушечные солдаты, оружие, мост, вода, пальмы, четыре окружения.
- Добор армии на трассе: +N, ×2, специалисты, улучшение оружия, временный форсаж.
- Клетки и ящики с прочностью: сначала прострелить, затем подобрать освобождённый отряд.
- Отрицательные ворота −N/÷2; мины, шипы, движущиеся пилы, пульсирующие лазеры.
- 12 миссий, 10 архетипов боссов, 12 классов бойцов и 14 типов противников.
- 24 артефакта, три командира, выживание, арсенал за заработанные кредиты.
- Русский интерфейс, клавиатура/мышь/касание, перенос старого локального сохранения.

Ворота выбираются по белому маркеру центра отряда: один эффект на ряд.
Физические ловушки проверяют позиции бойцов. Лимит армии — 120.
Рекрутирование и бой идут одновременно.

## Управление

Перетаскивай мышь или палец; также работают удерживаемые A/D и стрелки.
Стрельба автоматическая. Пробел/кнопка справа — способность, Esc — пауза.
Нота включает звук, HD/SD меняет качество. При уходе со вкладки бой останавливается.

## Запуск и проверка

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/
npm run check
npm run build
npm run test:campaign
# Короткий воспроизводимый участок без длинного запуска:
LEVEL_FROM=1 LEVEL_TO=3 SEED=73 npm run test:campaign
# Браузерные проверки также можно делить на отдельные запуски:
python tests/browser_smoke.py --offline --viewport desktop --output test-results/desktop
python tests/browser_smoke.py --offline --viewport mobile --output test-results/mobile
```

GitHub Pages: main → / (root). Все ресурсы локальные, пути относительные.
Node.js нужен только для тестов и сборки, не для запуска опубликованной игры.
Браузерный тест требует Python Playwright и Chromium.
Результат проверки кампании записывается после каждой миссии; границы диапазона
позволяют продолжить после прерывания, не повторяя весь набор.

## Проверено после финальной правки

53 автоматических теста и сборка прошли. 36/36 полных прохождений кампании
тестовым игроком: 12 миссий × seed 11, 73, 509, без бессмертия и выдачи войск.
Браузерные проверки 1280×900 и touch 390×844 прошли без JavaScript-ошибок.

Коммит 454c312c исправляет смертельные потери: «Второй шанс» теперь применяется
к бою, отрицательным воротам и физическим ловушкам одинаково. Без артефакта
следующий объект в том же кадре не может бесплатно оживить погибший отряд.

В проверочном Chromium использовался штатный software3d fallback и локальные
модули через import map. Аппаратный WebGL, HTTP-навигация и физические телефоны
не квалифицированы. Это также не замена пользовательской проверке баланса.
