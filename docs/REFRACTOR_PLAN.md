# План переработки R0–R7

Исходный опубликованный HEAD: de7a115b2d3216edfcdebe8eeb34a640ceaf9e01.
Цель: live crowd shooter, а не MMO. Яркая игрушечная графика — визуальный ориентир,
без копирования моделей/логотипов/аудио. Промокадры Top War не являются полной
спецификацией: конкретные ворота, ловушки и баланс — собственные проектные решения.

| Этап | Единственный фокус | Реализовано и проверяется |
|---|---|---|
| R0 | Контракты | Сохранить статический Pages и старый прогресс |
| R1 | Основа симуляции | Мировые координаты, fixed step, seed, формация и ограничения |
| R2 | Добор армии | +N/×2, специалисты, tier/buff, вскрытие клетки и подбор |
| R3 | Честные потери | Один выбор ворот на ряд; пространственные мины/пилы/шипы/лазеры |
| R4 | Уровни и боссы | 12 маршрутов, непрерывные волны и 10 многофазных боссов |
| R5 | Графика | Локальные WebGL2-модели, камера, эффекты, программный fallback |
| R6 | Продуктовый цикл | Артефакты, 3 командира, арсенал, UI, управление, сохранение |
| R7 | Регрессии и публикация | Тесты, кампании, browser smoke, non-force main update |

## Инварианты

- Размер viewport не меняет дальности, скорости и урон.
- Единственный frame loop. Пауза/выбор артефакта останавливают всю симуляцию.
- Ворота проверяют маркер центра; за один ряд нельзя получить два эффекта.
- Ловушки проверяют конкретных бойцов; промах не уменьшает армию.
- Контейнер сначала теряет HP, затем становится подбираемым отрядом.
- Армия <=120, враги <=700, эффекты ограничены, endless не копит весь журнал.
- Удары босса отмечены заранее и фиксируют цель до взрыва; уклонение работает.
- Победа, награды и потери не дублируются.
- Отсутствие localStorage не ломает запуск; старая версия сохранения переносится.
- Только локальные ресурсы, относительные пути, без регистрации, API и force push.

## Границы модулей

`src/data` — контент; `src/sim/rules.js` — чистые правила; `army.js` — численность;
`world.js` — трасса; `bosses.js` — атаки/фазы; `simulation.js` — фиксированный шаг;
`src/render` — модели и проекция; `src/main.js` — единственный цикл, UI и ввод.

## Граница квалификации

R5 реализован, но аппаратный WebGL2 в этом окружении не запустился. Browser smoke
проверяет штатный software3d fallback, а не GPU. HTTP и реальные мобильные устройства
не заявляются проверенными. Публикация и read-back выполняются отдельно.
