## Браузерные сценарии

Меню, выбор миссии, живой добор, мышь/касание, пауза, способность, заморозка
симуляции при выборе артефакта, применение артефакта, десять моделей боссов,
выживание, арсенал, единственный simulation clock после повторных запусков.
Проверка моделей боссов использует явно включённый QA-сценарий. Полные обычные
прохождения выполняет отдельный campaign runner без модификации боевых правил.

Параметр --viewport позволяет проверять desktop и mobile отдельными короткими
запусками. По умолчанию проверяются оба варианта.

## Ограничения проверки

HTTP-навигация проверочного Chromium блокируется политикой окружения:
ERR_BLOCKED_BY_ADMINISTRATOR. Browser smoke выполнялся с --offline: те же
локальные модули через import map, изменяются только спецификаторы импортов.
В браузере работал штатный software3d fallback, а не аппаратный WebGL.
Реальные iPhone/Android, аппаратный GPU и длительные сессии не проверены.
Успешный Pages workflow подтверждает публикацию, но не заменяет проверку
опубликованной игры на физическом устройстве.
