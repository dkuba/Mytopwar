## Ограничения

HTTP-навигация проверочного Chromium блокируется политикой окружения.
WebGL-контекст недоступен. Browser smoke выполнен с параметром --offline:
те же модули встроены через import map, меняются только пути импортов.
Работал штатный software3d fallback. Аппаратный GPU, реальные iPhone/Android,
длительные сессии и HTTP-хостинг этим тестом не проверены.

GitHub main и Pages проверяются отдельно по фактическим ref и workflow run.
Прежние сообщения об успешном push сами по себе не считаются подтверждением.
